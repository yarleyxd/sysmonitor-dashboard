## 📌 Sobre o projeto

O **SysMonitor Dashboard** é um sistema desenvolvido em Python para monitorar computadores, coletando informações sobre hardware, sistema operacional e rede, com visualização centralizada em um painel web.

## ✨ Funcionalidades

* 🖥️ Identificação dos computadores monitorados.
* ⚙️ Monitoramento do uso da CPU.
* 🧠 Acompanhamento da memória RAM.
* 💾 Informações sobre armazenamento.
* 🌐 Coleta de informações de rede.
* 📈 Visualização dos dados em um dashboard.
* 🔄 Envio de informações dos agentes para o servidor.

## 🛠️ Tecnologias utilizadas

| Tecnologia    | Utilização                             |
| ------------- | -------------------------------------- |
| 🐍 Python     | Desenvolvimento do sistema             |
| ⚡ FastAPI     | API e servidor                         |
| 📊 psutil     | Coleta de informações de hardware e sistema   |
| 🌐 HTML e CSS | Estrutura e aparência do painel        |
| 🟨 JavaScript | Interatividade e atualização dos dados |

## 🚀 Objetivo

Desenvolver uma ferramenta de monitoramento que facilite o acompanhamento dos recursos e do status dos computadores, centralizando as informações em uma única interface.
